# ☕ Kopi Sandikala

Kopi Sandikala adalah website company profile untuk sebuah coffee shop yang mengangkat konsep kopi Indonesia dengan tampilan modern, elegan, dan minimalis.

Website ini dirancang untuk memberikan informasi mengenai Kopi Sondokala, mulai dari cerita brand, pilihan menu, kategori produk, testimoni pelanggan, hingga informasi kontak.

---

## 📌 Tentang Website

Website Kopi Sondokala menggunakan konsep dark elegant dengan kombinasi warna hitam dan kuning/gold sebagai warna utama.

Tampilan website dibuat sederhana tetapi tetap menarik dengan fokus pada visual produk kopi dan informasi yang mudah dipahami oleh pengunjung.

### Konsep Website

* Modern
* Minimalis
* Elegan
* Dark theme
* Nuansa coffee shop
* Menggunakan aksen warna kuning/gold
* Responsive untuk berbagai ukuran layar

---

## 🎯 Tujuan

Website ini dibuat sebagai media informasi dan company profile untuk memperkenalkan Kopi Sondokala kepada calon pelanggan.

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

Clone repository GitHub ke komputer menggunakan:

```bash
git clone https://github.com/USERNAME/NAMA-REPOSITORY.git
```

Ganti:

```text
USERNAME
```

dengan username GitHub dan:

```text
NAMA-REPOSITORY
```

dengan nama repository project.

---

### 2. Masuk ke Folder Project

Setelah proses clone selesai:

```bash
cd NAMA-REPOSITORY
```

---

### 3. Jalankan Website

Jika website menggunakan HTML, CSS, dan JavaScript biasa, project dapat dijalankan dengan beberapa cara.

#### Cara 1 — Membuka langsung

Buka file:

```text
index.html
```

menggunakan browser.

#### Cara 2 — Menggunakan VS Code

Jika menggunakan Visual Studio Code, project dapat dijalankan menggunakan extension **Live Server**.

Langkahnya:

1. Buka folder project di VS Code.
2. Install extension **Live Server**.
3. Buka file `index.html`.
4. Klik kanan pada file.
5. Pilih **Open with Live Server**.
6. Website akan terbuka di browser.

## 🔧 Cara Mengubah Isi Website

### Mengubah Nama Brand

Buka:

```text
index.html
```

Kemudian cari teks:

```text
Kopi Sondokala
```

dan ubah sesuai nama brand yang diinginkan.

---

### Mengubah Menu

Cari bagian menu pada `index.html`.

Contohnya:

```html
<h3>Americano</h3>
<p>Kopi hitam dengan rasa yang kuat.</p>
```

Kemudian ubah nama, deskripsi, dan harga sesuai menu yang tersedia.

---

### Mengubah Gambar

Simpan gambar baru di folder:

```text
images/
```

Kemudian ubah source gambar pada HTML:

```html
<img src="images/menu/americano.jpg" alt="Americano">
```

---

### Mengubah Warna

Warna website dapat diubah melalui:

```text
css/style.css
```

Contoh:

```css
:root {
    --black: #000000;
    --white: #ffffff;
    --gold: #d4af00;
}
```

Jika ingin menggunakan warna lain, ubah nilai warna tersebut.
